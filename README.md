# Stop Risipa Alimentara

A Romanian educational website about reducing food waste, built as a static web project.

## What this project includes

- Informational pages about food waste and prevention tips
- A campaign/caravan page with an interactive Romania map concept
- Contact and involvement pages
- A small interactive game page
- Static HTML/CSS structure with image assets

## Why it matters

Food waste is both a social and environmental problem. This project presents the topic in a simple, accessible format and experiments with turning awareness into an interactive web experience.

## Tech stack

- HTML
- CSS
- Static assets and images

## Status

Portfolio / school project. The current version is static and can be improved with responsive cleanup, accessibility fixes, and a clearer deployment setup.
